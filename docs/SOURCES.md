# Sources techniques

Les choix du pipeline modernisé s'appuient sur les documentations officielles suivantes :

- [NCBI — règles d'utilisation des E-utilities](https://www.ncbi.nlm.nih.gov/books/NBK25497/) : URL dédiée, fréquence, paramètres `tool` et `email`, clés API et avertissement relatif aux résumés.
- [NCBI — paramètres ESearch et EFetch](https://www.ncbi.nlm.nih.gov/books/NBK25499/) : limite PubMed de 10 000 PMID, découpage des requêtes, XML et lots de récupération.
- [NCBI — APIs et jeux de données](https://www.ncbi.nlm.nih.gov/home/develop/api/) : point d'entrée officiel des services programmatiques.
- [NCBI — politiques et avertissements](https://www.ncbi.nlm.nih.gov/home/about/policies/) : conditions générales d'utilisation et attribution.
- [Microsoft — connecteur ODBC Power Query](https://learn.microsoft.com/fr-fr/power-query/connectors/odbc) : principe de connexion et actualisation d'une source ODBC dans Power BI.

La base incluse est un instantané académique. Les extraits agrégés ont été régénérés directement depuis cet instantané et non depuis une nouvelle collecte réseau.
